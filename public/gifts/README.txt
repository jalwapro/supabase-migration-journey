Jalwa Luxury Gifts (051-075) — 25 cinematic gift videos
=========================================================

Folders:
  webm/  — VP9 WebM optimized (~14 MB total, fast, recommended for Android/Chrome)
  mp4/   — H.264 MP4 optimized (~22 MB total, better iOS Safari support)

Upload steps for Hostinger:
1. Hostinger File Manager kholein (hPanel → File Manager)
2. public_html ke andar 'gifts' folder banayein
3. webm aur mp4 dono folders us gifts folder me upload karein
4. Public URL is tarah banega:
   https://yourdomain.com/gifts/webm/jalwa-diamond-watch.webm
   https://yourdomain.com/gifts/mp4/jalwa-diamond-watch.mp4

Uske baad mujhe apni domain URL bata dein (jaise https://yourdomain.com/gifts/),
main src/lib/luxuryGiftMp4.ts me sab URLs update kar dunga.
